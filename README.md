# 첨가물노트

기존 10개 식품과 추가로 선별한 50개 식품, 총 60개의 원재료와 출처를 읽는 한국어 웹앱입니다.

## 사용 기능

- 제품명·브랜드·제조사 검색과 분류, 정렬
- 신고 제품명에 표시된 월령 필터: 7개월 이상 4개, 9개월 이상 2개, 월령 미확인 54개
- 신고 제품 후보 전환과 후보별 원재료 원문 조회
- 제품명 일치 여부, 미확인 사항, 원본 CSV 행과 변경일 표시
- 성분 읽기 안내, 원문·출처 복사
- 브라우저 내 책갈피 저장
- 기존 10개는 기존 즐겨찾기와 병합하여 한 번만 기본 추가하며, 이후 사용자가 해제한 상태를 유지
- 포장지 사진에서 한국어·영어 문자 인식, 회전 및 영역 조정
- 인식 원문 수정·확인 후 포장지 노트로 브라우저에 저장

## 실행

`dist`를 정적 HTTP 서버로 제공하면 됩니다. 별도 설치나 빌드가 필요하지 않습니다.

## 데이터

`dist/data.js`에는 2026-11-02 검증한 기존 10개 식품과 2026-11-05 선별한 50개 식품, 총 64개 신고 후보 행이 들어 있습니다. 기존 10개는 판매명과 신고명의 매칭 상태를 유지합니다. 신규 50개는 CSV 신고 제품명으로 등록하며 현재 판매 상품과의 동일성이나 월령별 적합성을 확정하지 않습니다.

추가 구성: 이유식·진밥 17개, 유아식 소스 3개, 쌀과자 12개, 이유식 재료 8개, 유제품 8개, 동결건조 과일 2개. 원재료가 있는 행을 선별하고 같은 이름·제조사·허가일의 중복을 제외했습니다. 영양·안전 점수나 섭취 권장 목록이 아닙니다.

자료 범위: C002.csv 1,084,533행과 축산물품목제조보고.csv 571,277행. 각 후보에 파일명·데이터 레코드 번호·업체명·원재료·변경일·확인일을 보존합니다. 데이터 전체나 인증키는 포함하지 않습니다. 제품 그림은 실제 포장을 재현하지 않은 안내용 일러스트입니다.

C002.csv에서 전체 자릿수가 보존된 51개 후보에는 정확한 보고번호를 문자열로 표시합니다. 기존 식품 후보 9개는 이름·제조사·허가일과 원재료를 대조해 같은 행임을 확인하고 번호를 갱신했습니다. 축산물 후보 13개는 원문부터 지수 표기여서 정확한 번호로 활용하지 않습니다. 판매명과 신고 제품의 동일성, 함량, 복합원재료의 하위 성분을 추정해 채우지 않습니다. 실시간 API 조회는 아직 없습니다.

사진 인식에는 Tesseract.js 7.0.0과 한국어·영어 언어 자료를 사용합니다. 엔진과 모델은 vendor에서 같은 사이트 경로로 제공합니다. 사진은 브라우저 메모리에서 처리하며 서버로 전송하지 않습니다. 사용자가 확인한 텍스트만 localStorage에 보관합니다. 원재료 자동 분리는 보조 기능이며 사용자 확인 전에는 확정 데이터로 간주하지 않습니다.


## 첨가물 사전과 용도별 표시

`dist/additives.js`는 구연산, 구연산칼륨, 구연산철암모늄, 제삼인산나트륨, 폴리인산나트륨 5종의 이름·일반 용도·쉬운 설명·공식 출처·대조일을 보관합니다. 식약처 공전의 품목별 사용기준을 참고한 교육용 요약이며, 실시간 규정 조회나 제품 내 실제 목적·첨가량 검증은 아닙니다.

완전한 이름 또는 검토한 이명으로만 연결하고 중복은 하나로 셉니다. 신호등과 위험 색상은 사용하지 않습니다. 영양강화제는 영양 보충용, 산도조절제는 산도 조절용, 팽창제는 부풀림용으로 표시하고 상세에는 공식 용도명도 병기합니다. 복수 용도는 모두 표시하고 제품 단위에서는 중복 용도를 합칩니다. 제품별 실제 사용 목적은 미확인임을 안내합니다. 사전 일치 종류 수는 중립적인 숫자로만 보여줍니다. 사전에 없는 성분·혼합제제는 별도 확인 필요 목록에 남기며, 후보별 성분이 다르면 카드에서 확정 목록을 표시하지 않습니다. 전체 첨가물 수나 건강 등급을 판정하지 않습니다.

사진 원문은 사용자 확인 후 동일한 사전으로 대조합니다. 띄어쓰기만 정규화하고 쉼표·괄호 등으로 나누므로 함량이나 산지 등이 붙은 표기는 보수적으로 미확인 처리할 수 있습니다. 부정문·성분표 외 문장을 섞지 말고 실제 원재료 표시 부분을 확인해야 합니다. 기존 localStorage 키를 유지해 즐겨찾기와 기록을 보존합니다.


## 바코드·실물 사진 (v0.6)

Open Food Facts 공개 읽기 API v3를 바코드 제출 시 호출합니다. 브라우저에서 User-Agent 요청 매개변수와 앱 식별자를 전달합니다. 제품명·제품 앞면 사진·원재료·일부 영양 수치·첨가물/알레르기 코드를 원 출처와 함께 표시합니다. 외부 자료는 별도 화면에서만 다루고 국내 CSV와 자동 결합하거나 같은 제품으로 확정하지 않습니다. DB는 ODbL, 사진은 CC BY-SA 3.0이며 기여자·제품 페이지·라이선스 링크를 화면에 표시합니다. 조회 결과는 페이지 메모리에만 캐시하며 서버 DB나 저장소에 수집하지 않습니다.

GTIN 8/12/13/14자리와 체크 숫자를 검증합니다. 카메라 스캔은 BarcodeDetector 지원 브라우저만 가능하고, 미지원 기기에서는 숫자 입력을 사용합니다. 영상은 로컬 처리하고 모달 닫기·탭 숨김·30초 경과 시 트랙을 중단합니다. 바코드 번호만 외부 DB로 전송합니다. 조회 실패·미등록·요청 제한에는 포장지 OCR/직접 입력 대안을 제공합니다. 외부 사진 로딩 실패나 누락을 처리하며 임의의 사진을 대체하지 않습니다. 기존 60개는 바코드 근거가 없어 기존 일러스트를 유지합니다.

외부 한글 원재료는 사용자 대조 확인 후 기존 5종 사전으로 이름을 대조합니다. 외국어만 있는 자료는 한글 분석 불가를 표시하며 코드를 임의로 번역/위험 평가하지 않습니다. 외부 영양 수치는 미제공과 0을 구분합니다. 유카의 점수나 자체 건강 위험 등급은 제공하지 않으며, 식약처 실시간 API는 연결하지 않았습니다. 식약처 공전 근거 설명을 쓰는 기존 사전과 바코드 공개 DB를 각각 구분합니다.


## 외부 첨가물 코드의 쉬운 표시 (v0.7)

`dist/additive-codes.js`는 E327(젖산칼슘), E330(구연산), E575(글루코노델타락톤), E621(L-글루탐산나트륨/MSG)을 한글 이름·대표 용도·아이콘·한 줄 설명 카드로 표시합니다. 코드번호와 근거 링크를 보존하며, 원본 코드는 별도 접힌 항목에서 확인합니다. 국제번호/영문명은 Codex, 대표 용도는 식약처 또는 Codex 자료를 대조했습니다. 대표 용도는 모든 가능한 용도를 나열하거나 제품 내 실제 목적을 확정하는 것이 아닙니다. 미등록 코드와 하위 코드는 상위 코드로 추정하지 않고 설명 준비 중으로 남깁니다. 외부 코드 기반 안내는 기존 5종 한글 원재료 확인 사전과 구분됩니다. 위험도나 무첨가 여부를 추론하지 않습니다. 알레르기 태그도 등록된 한글 이름으로 표현하며 미제공과 없음은 구분합니다.
