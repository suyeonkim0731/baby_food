# 한입노트

10개 식품에 대한 공공데이터 검증 결과를 검색하고 원재료와 출처를 읽는 한국어 웹앱입니다.

## 사용 기능

- 제품명·브랜드·제조사 검색과 분류, 정렬
- 신고 제품 후보 전환과 후보별 원재료 원문 조회
- 제품명 일치 여부, 미확인 사항, 원본 CSV 행과 변경일 표시
- 성분 읽기 안내, 원문·출처 복사
- 브라우저 내 책갈피 저장

## 실행

`dist`를 정적 HTTP 서버로 제공하면 됩니다. 별도 설치나 빌드가 필요하지 않습니다.

## 데이터

`dist/data.js`에는 2026-11-02 검증한 10개 식품, 14개 신고 후보 행이 들어 있습니다. 데이터 전체나 인증키는 포함하지 않습니다. 제품 그림은 실제 포장을 재현하지 않은 안내용 일러스트입니다.

보고번호는 CSV 원문부터 지수 표기이므로 정확한 번호로 활용할 수 없습니다. 판매명과 신고 제품의 동일성, 함량, 복합원재료의 하위 성분을 추정해 채우지 않습니다. 실시간 API 조회 및 사진 자동 인식 기능은 아직 없습니다.
